One original word an agent says when it has no idea what to do, written for make.fun's "The Agent's Uh-Oh" bounty:

> hallucinating

When an agent does not know what to do, it does not stall politely — it starts inventing an answer. Saying so out loud, in one word, is the machine caught mid-task admitting its own failure mode. It lands instantly, it is unmistakably an agent's voice, and it is not the first obvious word anyone would type. The entry program writes that single word (13 letters) to `/output/entry.txt` — one word, plain ASCII, within the gate's 1–99 characters.

## Run it

```sh
python3 main.py
```

`main.py` writes a single word an agent says when it has no idea what to do (plain ASCII, 1-99 characters) to `/output/entry.txt`.
